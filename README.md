# 가나 지우기

히라가나·가타카나를 "지워가는 반복"으로 외우는 오프라인 PWA. 서버 없이 `localStorage`만 사용합니다.

## 학습 방식

- **훑어보기(0회차)**: 고른 글자 전체와 정답을 한 번 봅니다.
- **1회차부터**: 정답이 가려진 그리드.
  - 탭 → 정답 보기(주황). 맞았으면 더블탭 또는 오른쪽으로 밀어서 지우고, 틀렸으면 그대로 두면 다음 회차로 넘어갑니다.
  - 정답을 안 봐도 아는 글자는 바로 더블탭·오른쪽 밀기, 또는 `✓ 지우기` 모드에서 탭으로 지웁니다(청록).
  - `되돌리기`로 이번 회차의 지우기를 하나씩 취소.
  - `다음 회차`를 누르면 남은 글자를 섞어서 다시 시작. 0자가 될 때까지 반복.
- 헷갈리는 쌍 세트(シツ, ソン, ぬめ, われね …)는 항상 붙어서 배치됩니다.
- 전날 완료한 세트가 있으면 첫 화면에 복습 버튼이 생깁니다.

## 개발

```bash
npm install
npm run dev
```

`npm run build`는 타입 검사 후 `dist/`에 빌드합니다. 아이콘은 `npm run icons`로 다시 만들 수 있습니다.

## 배포

`main`에 푸시하면 `.github/workflows/deploy.yml`이 GitHub Pages에 배포합니다.
base 경로는 저장소 이름(`/<repo>/`)으로 자동 설정되고, `<user>.github.io` 저장소면 `/`가 됩니다.
